# Shared Schemas

This directory contains data contracts shared across backend, intelligence, and
frontend modules.

Planned schemas include:

- Agent configuration
- Tool definitions
- Security constraints
- Threat model entries
- Attack definitions
- Execution runs
- Tool traces
- Security findings
- Regression test records

## Important

The final constraint schema is owned by the security/constraint work and will
be finalized before dependent modules are integrated.

Do not introduce incompatible schema changes without discussing them with the
team.
